# during
这是一个为 *during* 代码而准备的编译器，它作为一门编程语言在这。
它将代码编译为C代码，并且加入一些很不错的只有高级编程语言才具备的特性比如函数重载、小开销的类等等。
它很像C++，但是C++过于繁杂，而且不同的编译器有不同的用法。但讽刺的是，这个项目的全部无一例外都是C++写的
而且它很严格，轻量还很酷。

## 主义
所有东西都应该写下来十分简单。去往 Python3 中的 *import this*？
即使有很多语言能完成这个，它也很简易去写代码，因为它读起来很像英语。
当然，它具备自动内存释放功能，但不是自动垃圾回收。它加入这些内存需要释放的函数在应该要有的地点。
