# during
It is a compiler for **during** code and it is as a programming language here.
It compiles the code into C code. And add some great things and only high-level programming languages have it like function overloading, classes of small-scale expenditure and so on.
It is like C++ but C++ is too complex and different compliers have different usages. But ironically, all of the project made of C++.
So it is strict, bright and so cool.

## Idea
It do NOT has any symbols like +, -, *, /, !, = and so on.
Everything is identifier or UPPER keyword like BIGGER, SMALLER, QUALS and so on.
So it is easy to read code of it because it looks like English although there is already some progrmming languages so are they.
Of course, it has automatic memory release but not automatic GC. It is add functions at places these heap memory needs to free.
